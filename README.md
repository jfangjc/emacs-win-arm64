# Emacs for Windows ARM64

Unofficial GNU Emacs builds for Windows 11 ARM64 using MSYS2 CLANGARM64.
Daily automation checks stable and pretest channels and publishes new versions.

- `emacs-arm64.zip`: portable.
- `emacs-arm64-setup.exe`: per-user installer.
- `emacs-arm64-source.tar.xz`: dependency sources, ARM64 patch and build recipe.

Release notes include SHA-256 checksums and the upstream GNU Emacs source link.
